# Campus Task Manager

## Project Overview
Campus Task Manager is a student-focused task management application designed to help students organize academic activities, manage assignments, track deadlines, and improve productivity.

This project is being developed as part of an Agile Fundamentals practical assignment.

## Objectives
- Organize academic tasks in one place.
- Help students manage assignment deadlines.
- Track task progress.
- Improve time management and productivity.
- Practise Agile software development and team collaboration.

## Planned Features
1. Create and manage tasks.
2. Add task descriptions and deadlines.
3. Track task status.
4. View an organized task dashboard.
5. User registration and login.
6. Deadline reminders (future enhancement).

## Branching Strategy
We use a feature branch workflow.

- main: Contains the stable and approved project version.
- feature branches: Used to develop individual features.
- docs branches: Used for documentation changes.

Example branch names:
- feature/add-task-form
- feature/user-login
- docs/update-readme

## Development Workflow
1. Create an issue describing the task.
2. Create a branch from main.
3. Develop the required feature.
4. Commit the changes.
5. Push the branch to GitHub.
6. Create a Pull Request.
7. Review and approve the changes.
8. Merge the approved Pull Request into main.
